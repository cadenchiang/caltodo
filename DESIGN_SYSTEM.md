# caltodo design system

The concrete tokens, primitives, and recipes behind `UI_STYLE_GUIDE.md`. Every value is traced to
a real file; citations are `path:line`. When code and this doc disagree, the code wins: fix the doc.

> Sibling docs: [`CLAUDE.md`](./CLAUDE.md) (conventions) and [`UI_STYLE_GUIDE.md`](./UI_STYLE_GUIDE.md)
> (the decisions). This file is the reference; the guide is the rulebook. They must not disagree.

## How to use this doc

1. Use the primitives in `src/components/ui/` first. They render the recipes below verbatim.
2. Never hardcode a color for themed UI. Use the CSS-variable-backed utilities (`bg-card`,
   `text-foreground`, `border-border`) so every theme and dark mode adapts.
3. Before adding a component, run the [checklist](#adding-a-new-component).

danger must mean the same thing in Miffy pink and Forest green.

Extra tokens: `--flipcard-bg`/`--flipcard-text` (clock widget, `globals.css:2394`);
`--widget-text-color`/`--widget-accent-color` (per-widget overrides, `globals.css:2050-2072`).

### Accent ramp

The default (caltodo) ramp lives in `@theme inline` (`globals.css:341-351`). It is one hue:

| Step | Value | Role |
|---|---|---|
| `blue-400` | `#2a9bdd` | Lighter accent (dark-mode text) |
| `blue-500` | `#0e89d6` | Brand blue, the accent |
| `blue-600` | `#0c78bd` | Hover (`hover:bg-blue-600`) |
| `blue-700` | `#0a67a3` | Pressed |

`--color-accent-hover` aliases `blue-600` (`globals.css:355`) so `bg-accent-hover` is the hover
token where a class name is needed; the literal `#3D8FE8` is retired. Every `.theme-*` block
overrides the whole `--color-blue-*` ramp with its own accent (`globals.css:363-1030`).

**Known limit:** the ramp is declared inside `@theme inline`, so Tailwind inlines the default
values into `bg-blue-500` and friends. The per-theme `--color-blue-*` overrides only reach CSS
that references `var(--color-blue-*)` (for example `bg-accent-hover`), not the compiled `bg-blue-*`
utilities. See [Known inconsistencies](#known-inconsistencies).

`.force-light` (`globals.css:1635-1660`) pins tokens to their light values on always-white
marketing and auth pages.

## Spacing and layout

- App shell: flex column `h-dvh`; desktop sidebar plus `<main>` row (`src/app/app/layout.tsx`).
- Main content padding: `px-4 md:px-10` with `pt-[max(1rem,env(safe-area-inset-top))]`.
- Desktop sidebar: `w-52`, `px-3 pb-4`, `glass-strong` (`Sidebar.tsx:119`).
- Widths: `max-w-sm` (confirms), `max-w-md` (forms), `max-w-lg`, `max-w-2xl` (lists); these are
  `Modal`'s `sm` / `md` / `lg` / `xl`.
- Modal padding `p-6`; card padding `p-4` or `px-6 py-4`; section gaps `space-y-4` /
  `space-y-5`; button gaps `gap-2`; icon-to-label `gap-1.5`.
- Safe areas: `body` adds `padding-bottom: env(safe-area-inset-bottom)` (`globals.css:1060`).

### Z-index ladder (`globals.css:22-26`)

| Utility | Value | Holds |
|---|---|---|
| `z-sticky` | 40 | Sticky headers, tab bars |
| `z-dropdown` | 50 | Popovers, menus, anchored pickers |
| `z-overlay` | 100 | Modals and backdrops (`Modal`, `TaskCreateModal`) |
| `z-toast` | 200 | Toasts (`ToastContext.tsx`) |
| `z-tooltip` | 300 | Tooltips |

`z-10` to `z-40` remain for local stacking. Arbitrary values (`z-[9999]`, `z-[10001]`) are legacy
and migrate to the ladder; a nested dialog goes on `z-overlay` and wins by DOM order.

## Radii and elevation

- Controls and inputs: `rounded-lg` (`Button`, `IconButton` square, `TextField`, `TextArea`).
- Cards and modals: `rounded-2xl`. Popovers: `rounded-xl`.
- Pills, count badges, icon buttons: `rounded-full`. Other badges: `rounded-md`.
- Task checkbox: `rounded-[4px]` (`src/components/tasks/shared/TaskCheckbox.tsx`).
- Board widget card: `.board-widget-card` (`globals.css:2498`), 16px radius, `--border`, subtle
  single-layer shadow.

Elevation: glass layers (`globals.css:1138-1178`); `.btn-elevated` family (`1551-1612`) zeroes its
shadow in `.dark`; modals `shadow-2xl`; popovers `shadow-lg`; elevated buttons `shadow-sm
dark:shadow-none`. Scrollbars are thin and theme-tinted (`1103-1130`); `.scrollbar-none` hides
them (`2312`).

removed; `shake`, `appear`, `fade-left/right`, `page-in`, `sync-bar`, `sync-glow`,
`border-spin`, `backdrop-out`, `dialog-out` no longer exist.

**Reduced motion** (`globals.css:1083-1092`): a global `prefers-reduced-motion` rule collapses
every animation and transition to 0.01ms. `animate-spin` and `.motion-essential` are exempt.

**Focus** (`globals.css:1071-1074`): `:where(:focus-visible):not(.react-grid-item)` draws
`outline: 2px solid var(--ring)` with a 2px offset. Zero specificity, so component rings win;
react-grid-layout's own `outline: none !important` reset (`2207`) is left alone.

## Accessibility

- **Focus:** the global `:focus-visible` ring covers everything; primitives add
  `focus-visible:ring-2 focus-visible:ring-ring`. Never `focus:outline-none` without a ring.
- **Names:** `IconButton` requires `aria-label`; `TextField` / `TextArea` require `label`.
- **Dialogs:** `Modal` traps focus, sets initial focus, restores focus, closes on Escape, locks
  scroll, and carries `role="dialog" aria-modal aria-labelledby`.
- **Forms:** errors link through `aria-describedby` and set `aria-invalid`.
- **Toasts:** `role="status" aria-live="polite"`; never the only channel for critical info.
- **Motion:** honored globally through `prefers-reduced-motion`.
- **Dark-mode shadows:** elevated buttons set `dark:shadow-none`.
- **Autofill:** `-webkit-autofill` overrides keep inputs theme-correct (`globals.css:1615-1660`).
- **Theme flash:** dark and theme classes are applied pre-paint (`layout.tsx:113-170`).

## Adding a new component

- [ ] Start from a primitive. Extend it before writing a new recipe.
- [ ] CSS-variable colors only. No `text-gray-*`, `bg-white`, or `bg-[#hex]` for themed elements.
- [ ] No uppercase labels. Sentence case, `text-foreground`.
- [ ] `bg-popover` for anything floating. Never translucent.
- [ ] Radii: controls and inputs `rounded-lg`; cards and modals `rounded-2xl`; popovers `rounded-xl`;
      pills, count badges, icon buttons `rounded-full`; badges `rounded-md`.
- [ ] `dark:shadow-none` on any elevated button. Test in `.dark` and in Miffy.
- [ ] Z-index from the ladder, never an arbitrary value.
- [ ] Text sizes from the scale: `text-2xs` and `text-3xs`, not `text-[11px]` / `text-[10px]`.
- [ ] Lucide icons, 16 default; `aria-label` on icon-only controls; labels on every input.
- [ ] Copy from `src/lib/copy.ts`; sentence case; lowercase brand; no em dashes.
- [ ] Reuse an existing animation; looping motion must survive the reduced-motion collapse only if essential.
- [ ] Files under 300 lines, one purpose, docstrings, a test in `src/__tests__/`.

## Known inconsistencies

Candidates for cleanup, measured with grep on `src/`:

1. **Hardcoded grays and hexes** remain across `src/components` and `src/app` (hundreds of
   `text-gray-*` / `bg-gray-*` / `bg-white` and ~560 hex literals). Migrate to tokens per page.
2. **Accent utilities do not follow themes.** Because the ramp is declared in `@theme inline`,
   `bg-blue-500` compiles to the literal `#0e89d6` and the `.theme-*` `--color-blue-*`
   overrides only affect `var(--color-blue-*)` references. Moving the ramp to a non-inline
   `@theme` would make utilities theme-aware; it changes every theme's rendering, so it is a
   deliberate follow-up.
3. **Legacy overlays** still use `z-[9999]` / `z-50` and hand-rolled focus handling (about 55
   files). They should adopt `Modal` / `Popover` and the z ladder; until then, a legacy
   `z-[9999]` overlay still sits above `z-toast`.
4. **Gray uppercase labels** persist in `ContactForm.tsx`, `admin/StatCard.tsx`,
   `admin/RetentionTable.tsx`, `CalendarDayCell.tsx`, `onboarding/page.tsx`,
   `weather-displays/DetailedDisplay.tsx`.
5. **Duplicate relative-date helpers** in `SyllabusPreview.tsx`, `discussions/DateSeparator.tsx`,
   `NewAssignmentsModal.tsx`, `gcal-displays/helpers.ts`, `date-presets.ts` should call
   `getRelativeDateLabel`.
6. **`text-[11px]` / `text-[10px]` literals** (~165) should become `text-2xs` / `text-3xs`.
7. **`TypingIndicator.tsx`** still carries an inline `<style>` for `typing-bounce`; the keyframes
   now live in `globals.css:1096` and the inline block can go (discussions package).
8. **`bg-foreground text-background`** inverted buttons remain in ~14 files; use
   `Button variant="inverted"`.
